# Hierarchical Clustering Assignment

## 1. Iris Dataset with Ward Linkage and Dendrogram

```python
from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler
from scipy.cluster.hierarchy import linkage, dendrogram
import matplotlib.pyplot as plt

# Load Iris dataset
iris = load_iris()
X = iris.data

# Standardize the data
X_scaled = StandardScaler().fit_transform(X)

# Hierarchical clustering using Ward linkage
Z = linkage(X_scaled, method='ward')

# Plot dendrogram
plt.figure(figsize=(12, 6))
dendrogram(Z)
plt.title("Hierarchical Clustering Dendrogram - Ward Linkage")
plt.xlabel("Sample Index")
plt.ylabel("Distance")
plt.grid()
plt.show()
```

### Explanation

The Iris dataset contains 150 samples and 4 features. First, the data is standardized so that all features have a similar scale. The `ward` linkage method then performs hierarchical clustering, and `dendrogram()` displays the resulting hierarchy.

---

## 2. Cut the Dendrogram into 3 Clusters

We can use `fcluster()` with the `distance` criterion to create 3 clusters.

```python
from scipy.cluster.hierarchy import fcluster
import numpy as np

# Choose a distance threshold after inspecting the dendrogram
height = 7

# Create 3 clusters
clusters = fcluster(
    Z,
    t=height,
    criterion='distance'
)

# Print cluster assignments
print("Cluster assignments:")
print(clusters)

# Count samples in each cluster
unique, counts = np.unique(clusters, return_counts=True)

print("\nNumber of samples in each cluster:")

for cluster, count in zip(unique, counts):
    print("Cluster", cluster, ":", count, "samples")
```

### Note

The exact height depends on the dendrogram you obtain. If `height = 7` does not produce exactly 3 clusters in your environment, look at the dendrogram and adjust the height slightly until the horizontal cut crosses **3 major branches**.

## 3. Compare Ward, Single, and Complete Linkage

```python
import matplotlib.pyplot as plt
from scipy.cluster.hierarchy import linkage, dendrogram

# Create linkage matrices
Z_ward = linkage(X_scaled, method='ward')
Z_single = linkage(X_scaled, method='single')
Z_complete = linkage(X_scaled, method='complete')

# Create three dendrograms
plt.figure(figsize=(18, 6))

# Ward linkage
plt.subplot(1, 3, 1)
dendrogram(Z_ward, no_labels=True)
plt.title("Ward Linkage")
plt.xlabel("Samples")
plt.ylabel("Distance")

# Single linkage
plt.subplot(1, 3, 2)
dendrogram(Z_single, no_labels=True)
plt.title("Single Linkage")
plt.xlabel("Samples")
plt.ylabel("Distance")

# Complete linkage
plt.subplot(1, 3, 3)
dendrogram(Z_complete, no_labels=True)
plt.title("Complete Linkage")
plt.xlabel("Samples")
plt.ylabel("Distance")

plt.tight_layout()
plt.show()
```

### Comparison

**Ward linkage:** Tries to create compact and similarly sized clusters by minimizing the increase in within-cluster variance.

**Single linkage:** Uses the closest pair of points between clusters. It can create long, chain-like clusters and is more sensitive to noise.

**Complete linkage:** Uses the farthest pair of points between clusters. It tends to produce tighter and more compact clusters.

Therefore, the dendrograms have different branch structures and heights because each linkage method calculates the distance between clusters differently.

---

## 4. Interpretation of the Dendrogram

The height of a branch represents the distance at which two clusters are joined. Clusters that merge at a low height are more similar to each other because their points are close together. Clusters that merge at a high height are more different because a larger distance is required to combine them. Large vertical gaps in the dendrogram are useful places to make a cut and determine the number of clusters.
