## 4. Correlation Heatmap

```python

numerical_data = df[
    ["Age", "Annual Income (k$)", "Spending Score (1-100)"]
]

# Create correlation matrix
correlation = numerical_data.corr()

# Plot heatmap
plt.figure(figsize=(8, 5))

sns.heatmap(
    correlation,
    annot=True,
    cmap="coolwarm",
    fmt=".2f"
)

plt.title("Correlation Matrix")
plt.show()

# Print correlation matrix
print(correlation)
```

### Interpretation

The heatmap shows the strength of relationships between the numerical features.

In the standard Mall Customers dataset, **Age and Spending Score** have the strongest correlation among these three features, but the relationship is still relatively weak. Annual Income and Spending Score also do not have a strong linear correlation.

**Important:** Correlation shows the strength of a linear relationship; it does not mean that one feature causes another.

## 5. Apply K-Means Clustering

We will use only:

* `Annual Income (k$)`
* `Spending Score (1-100)`

We will create **3 clusters** and use `random_state=42` as required.

```python
from sklearn.cluster import KMeans

# Select only the required features
X = df[
    ["Annual Income (k$)", "Spending Score (1-100)"]
]

# Create K-Means model
kmeans = KMeans(
    n_clusters=3,
    random_state=42,
    n_init=10
)

# Fit and predict clusters
df["Cluster"] = kmeans.fit_predict(X)

# Display the data with cluster assignments
print(df.head(10))

# Display number of customers in each cluster
print("\nCustomers in each cluster:")
print(df["Cluster"].value_counts().sort_index())
```

### Explanation

`KMeans(n_clusters=3)` divides the customers into 3 groups based only on **Annual Income** and **Spending Score**.

The new `Cluster` column contains the cluster assigned to each customer.

For example:

```text
CustomerID    Age    Annual Income    Spending Score    Cluster
1             19     15               39                 1
2             21     15               81                 2
3             20     16               6                  1
...
```

The exact cluster numbers (`0`, `1`, `2`) are assigned by K-Means and **do not have an inherent meaning**. For example, Cluster 0 is not automatically "low income"; you interpret each cluster by examining its centroid.

### Optional: Visualize the 3 Clusters

```python
import matplotlib.pyplot as plt

plt.figure(figsize=(8, 6))

plt.scatter(
    df["Annual Income (k$)"],
    df["Spending Score (1-100)"],
    c=df["Cluster"]
)

# Plot centroids
centroids = kmeans.cluster_centers_

plt.scatter(
    centroids[:, 0],
    centroids[:, 1],
    marker="X",
    s=200,
    label="Centroids"
)

plt.xlabel("Annual Income (k$)")
plt.ylabel("Spending Score (1-100)")
plt.title("Customer Segmentation using K-Means")
plt.legend()
plt.grid()
plt.show()
```

This final graph makes it easy to see the **3 customer segments** and their K-Means centroids.
