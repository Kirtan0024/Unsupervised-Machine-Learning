## 1. Random dataset of 10 users

```python
import random

users = []

for i in range(1, 11):
    user = {
        "user_id": i,
        "daily_app_opens": random.randint(1, 20),
        "avg_session_duration": round(random.uniform(2, 60), 2)
    }
    users.append(user)

print(users)
```

```text

 {'user_id': 1, 'daily_app_opens': 5, 'avg_session_duration': 18.42},
 {'user_id': 2, 'daily_app_opens': 12, 'avg_session_duration': 35.71},
 ...
]
```

## 2. Supervised vs Unsupervised Learning

| Point                 | Supervised Learning                                         | Unsupervised Learning                                      |
| --------------------- | ----------------------------------------------------------- | ---------------------------------------------------------- |
| **Data**              | Uses labeled data                                           | Uses unlabeled data                                        |
| **Goal**              | Predict a known target/output                               | Find hidden patterns or groups                             |
| **Example**           | Instagram feed ranking predicts which posts a user may like | Spotify groups songs/users with similar listening behavior |
| **Common techniques** | Classification, Regression                                  | Clustering, Association                                    |
| **Output**            | Predicted class/value                                       | Groups, patterns, or relationships                         |

**Simple example:**
Instagram can use supervised learning when it learns from labeled user interactions such as likes, comments, and clicks to predict which posts should appear higher in the feed. Spotify can use unsupervised learning to group songs based on characteristics such as listening frequency, genre, and audio features without predefined labels.

## 3. Product Segmentation into Clusters

Suppose we have these 8 products:

| Product | Price (₹) | Reviews |
| ------- | --------: | ------: |
| A       |       500 |      20 |
| B       |       600 |      25 |
| C       |       700 |      30 |
| D       |     1,500 |     150 |
| E       |     1,600 |     170 |
| F       |     1,800 |     160 |
| G       |     5,000 |     600 |
| H       |     5,500 |     650 |

### Cluster 1 — Low price, low popularity

**A, B, C**

* Price: ₹500–₹700
* Reviews: 20–30
* These products are inexpensive and have relatively few reviews.
* They represent **low-price / low-popularity products**.

### Cluster 2 — Medium price, medium popularity

**D, E, F**

* Price: ₹1,500–₹1,800
* Reviews: 150–170
* These products have similar prices and considerably more reviews than Cluster 1.
* They represent **medium-price / medium-popularity products**.

### Cluster 3 — High price, high popularity

**G, H**

* Price: ₹5,000–₹5,500
* Reviews: 600–650
* These are expensive products with a very large number of reviews.
* They represent **high-price / high-popularity products**.

**Reasoning:** Both **price and number of reviews** are considered. Products with similar values for both features are placed in the same cluster.

## 4. Unsupervised Learning Applications

| App          | Scenario                                    | Data Required                                        | Possible Insight                                                 |
| ------------ | ------------------------------------------- | ---------------------------------------------------- | ---------------------------------------------------------------- |
| **Zomato**   | Group customers by ordering behavior        | Orders, cuisine, spending, order frequency           | Discover budget customers, frequent customers, premium customers |
| **Flipkart** | Group products based on purchasing patterns | Product category, price, purchases, ratings          | Find products frequently bought by similar customers             |
| **Spotify**  | Group users based on listening behavior     | Songs played, genres, artists, skips, listening time | Discover different listener groups and improve recommendations   |

For example, Spotify could discover a group of users who frequently listen to **Bollywood + Punjabi music**, even if that group was not predefined beforehand.

## 5. Real-world dataset for Customer Segmentation

A very suitable dataset is the **Mall Customer Segmentation Dataset** on Kaggle.

[Kaggle — Mall Customer Segmentation Dataset](https://www.kaggle.com/datasets/shwetabh123/mall-customers?utm_source=chatgpt.com)

### Dataset structure

The dataset contains **200 customers** and commonly includes these 5 features:

| Feature        | Type        | Description                |
| -------------- | ----------- | -------------------------- |
| CustomerID     | Numeric     | Unique customer identifier |
| Gender         | Categorical | Male/Female                |
| Age            | Numeric     | Customer age               |
| Annual Income  | Numeric     | Annual income in thousands |
| Spending Score | Numeric     | Customer spending score    |

**Labels:** The dataset is effectively **unlabeled for clustering purposes**. There is no predefined customer-segment/class label that the clustering algorithm has to predict.

### Why it is useful

You can apply **K-Means clustering** to features such as:

* Annual Income
* Spending Score
* Age

and discover groups such as:

* Low-income, low-spending customers
* High-income, high-spending customers
* High-income, low-spending customers
* Young, high-spending customers

This makes it an excellent dataset for demonstrating **unsupervised learning and customer segmentation**.
